# TopUpKu

Platform PPOB modern untuk pulsa, paket data, PLN, game, dan e-wallet.  
Dibangun dengan **Next.js 15**, **TailwindCSS**, **Prisma**, dan **PostgreSQL**.

## 🚀 Fitur
- Landing Page premium
- Checkout flow dengan integrasi Tripay
- Admin Dashboard untuk pantau penjualan & keuntungan
- Role-based access (Admin/User)
- Export laporan transaksi

## ⚙️ Cara Jalankan
1. Clone repo ini
2. Install dependencies: `npm install`
3. Setup `.env` sesuai contoh `.env.example`
4. Jalankan lokal: `npm run dev`
5. Deploy ke Vercel → website langsung online
